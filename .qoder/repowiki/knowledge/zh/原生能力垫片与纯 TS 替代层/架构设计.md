- **目录分层**：`src/native-ts/` 存放核心算法的纯 TS 实现（如 `yoga-layout`, `file-index`, `color-diff`），`shims/` 存放针对特定 NAPI 模块或外部依赖的桩代码。
- **重定向模式**：`shims/*-napi` 下的入口文件（如 `color-diff-napi/index.ts`）通过 `export ... from '../../src/native-ts/...'` 将调用透明重定向至 TS 实现，确保 API 契约一致。
- **桩实现策略**：针对 macOS 专属功能（如 `ant-computer-use-*`），在 `shims/` 中提供返回空值或默认值的 Stub 对象，并通过 `process.platform === 'darwin'` 进行环境隔离。
- **枚举定义**：在 `src/native-ts/yoga-layout/enums.ts` 中使用 `const` 对象配合 `typeof` 映射来定义类型，以符合仓库的编码规范并避免 TS enum 的运行时开销。
