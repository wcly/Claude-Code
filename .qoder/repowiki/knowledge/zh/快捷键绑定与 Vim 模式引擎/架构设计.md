- **核心分层**：`keybindings` 模块负责通用快捷键生命周期管理，通过 `KeybindingProviderSetup` 初始化并监听用户配置热重载；`resolver.ts` 提供纯函数式的按键匹配与 Chord 状态转换逻辑。
- **Vim 状态机**：`vim` 模块定义了严格的 `VimState` 与 `CommandState` 类型系统，通过 `motions.ts` 等纯函数计算光标位移，与 React 状态解耦。
- **拦截机制**：采用 `ChordInterceptor` 组件在 React 树顶层注册 `useInput`，利用 `stopImmediatePropagation` 优先处理多键序列，防止事件泄露至普通输入框。
- **上下文优先级**：通过 `KeybindingContext` 管理活跃上下文集合，实现特定场景（如主题选择器）快捷键对全局绑定的动态覆盖。
