- 纯函数设计：核心逻辑如 `resolveKeyWithChordState` 和 `resolveMotion` 均定义为无副作用的纯函数，仅依赖输入参数进行状态计算。
- Ref 与 State 协同：在高频输入场景中，使用 `useRef` 存储即时状态（如 pendingChord）以确保同步访问，同时使用 `useState` 触发必要的 UI 重渲染。
- 类型驱动的状态机：Vim 模式利用 TypeScript 判别联合类型（Discriminated Unions）定义 `CommandState`，确保在处理不同命令阶段（如 operator, count, find）时的类型安全与 exhaustive checking。
