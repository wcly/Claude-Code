- `cli.tsx` 作为主引导入口，采用动态导入（dynamic imports）和特性开关（feature flags）实现多路径快速启动（如 daemon, bridge, background sessions），以最小化模块加载开销。
- `mcp.ts` 基于 `@modelcontextprotocol/sdk` 实现标准 MCP 服务器，通过 `StdioServerTransport` 暴露内部工具集。
- `agentSdkTypes.ts` 作为 SDK 的类型聚合层，重新导出核心序列化类型（`coreTypes`）、运行时接口（`runtimeTypes`）及控制协议类型（`controlTypes`）。
- `sdk/` 子目录包含详细的 Zod 模式定义（如 `sandboxTypes.ts`）及其生成的 TypeScript 类型，构成了 SDK 配置与通信的数据契约基础。
