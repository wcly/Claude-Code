- **核心入口与生命周期**：`Ink` 类 (`ink.tsx`) 作为运行时控制器，管理 `react-reconciler` 容器、双缓冲帧 (`Frame`) 和终端 I/O。它协调从 React 提交到物理终端写入的完整流水线。
- **虚拟 DOM 与布局**：`dom.ts` 定义了自定义宿主环境（Host Environment），将 React 元素映射为带有 Yoga 布局节点的 DOM 结构。`reconciler.ts` 实现了 `react-reconciler` 的宿主配置，处理节点创建、属性更新和布局计算触发。
- **渲染流水线**：采用“React 渲染 -> Yoga 布局 -> 屏幕缓冲生成 -> 增量差分 (Diff) -> 终端写入”的流程。`renderer.ts` 遍历 DOM 树生成屏幕缓冲，`log-update.ts` 和 `screen.ts` 负责计算最小变更集并应用 ANSI 转义序列。
- **事件与焦点系统**：`events/dispatcher.ts` 实现了类似浏览器的捕获/冒泡事件分发机制。`focus.ts` 管理焦点栈和 Tab 键导航，支持无障碍访问。
- **终端协议解析**：`termio/` 目录包含 ANSI 转义序列的解析器 (`parser.ts`) 和生成器，处理鼠标、键盘扩展协议（如 Kitty 协议）及窗口大小调整。
