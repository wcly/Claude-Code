- **启动编排**：`src/entrypoints/cli.tsx` 作为主入口，利用 `feature()` 门控和动态 `import()` 实现多路径快速启动（如版本查询、守护进程、桥接模式），避免全量模块加载。
- **UI 集成**：在常规交互模式下，初始化 `Ink` 实例并挂载 React 根组件，将 `src/ink` 提供的声明式 UI 引擎注入到标准输出流中。
- **通信抽象**：通过 `src/cli/transports/Transport.ts` 定义的统一接口，解耦具体的通信实现（如 WebSocket、SSE），使上层业务逻辑无需感知底层连接细节。
- **全局初始化**：`src/entrypoints/init.ts` 负责在信任建立后异步配置遥测、策略限制及远程设置，确保运行时环境的完整性。
