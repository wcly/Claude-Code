- **Structured I/O Core**: `structuredIO.ts` implements a bidirectional NDJSON protocol over stdio, managing permission requests (`can_use_tool`), hook callbacks, and MCP message forwarding via a request-response pattern with UUID correlation.
- **Transport Abstraction**: Defines a `Transport` interface implemented by `SSETransport` (for CCR v2 remote sessions using SSE reads and HTTP POST writes) and `HybridTransport` (WebSocket reads with serialized batched HTTP POST writes via `SerialBatchEventUploader`).
- **Remote Session Management**: `remoteIO.ts` extends `StructuredIO` to support remote execution, integrating `CCRClient` for worker lifecycle management (heartbeats, epoch tracking, state reporting) and internal event persistence.
- **Command Handlers**: Modular handlers in `handlers/` (e.g., `auth.ts`, `mcp.tsx`, `agents.ts`) implement specific CLI subcommands, often leveraging lazy dynamic imports and shared exit utilities (`exit.ts`).
