- **核心入口**：`permissions.ts` 中的 `hasPermissionsToUseTool` 函数作为权限检查的统一入口，协调规则匹配、钩子执行和分类器调用。
- **规则引擎**：通过 `PermissionRule` 体系支持 Allow/Deny/Ask 三种行为，支持全局、会话级及 MCP 服务器维度的细粒度配置。
- **自动化决策层**：集成 `yoloClassifier.ts` 实现“自动模式”，利用两阶段 XML 分类器（快速判断 + 深度推理）在无需用户干预的情况下评估高风险操作。
- **状态追踪**：通过 `denialTracking.ts` 监控连续拒绝次数，在达到阈值时自动降级为交互式提示，平衡安全性与用户体验。
- **命令解析支撑**：依赖 `bash/commands.ts` 进行复杂的 Shell 命令拆分、重定向提取及注入攻击检测，为权限判断提供准确的语义输入。
