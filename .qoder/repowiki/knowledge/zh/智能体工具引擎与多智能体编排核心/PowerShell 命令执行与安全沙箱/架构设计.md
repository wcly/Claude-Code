- **核心执行层**：`PowerShellTool.tsx` 作为入口，通过 `runPowerShellCommand` 生成器管理任务生命周期，支持前台进度轮询与后台自动降级（Auto-backgrounding）。
- **安全验证层**：采用多层防御架构。`readOnlyValidation.ts` 基于 `CMDLET_ALLOWLIST` 进行只读命令白名单匹配；`powershellSecurity.ts` 利用 AST 解析检测动态调用、下载执行（Download Cradle）及特权提升等危险模式；`clmTypes.ts` 维护 Microsoft Constrained Language Mode 允许的类型白名单，拦截非安全 .NET 类型访问。
- **权限决策层**：`powershellPermissions.ts` 聚合上述验证结果，结合 `dangerousCmdlets.ts` 中的危险命令集（如 `Invoke-Expression`、`Start-Process`），决定命令是自动允许、拒绝还是触发用户权限询问。
