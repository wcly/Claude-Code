- **核心入口**：`ToolSearchTool.ts` 通过 `buildTool` 构建名为 `ToolSearch` 的工具，支持 `select:<name>` 精确选择和关键词模糊搜索。
- **搜索算法**：内部实现了基于词边界正则的评分机制，对工具名称（区分 MCP 前缀）、描述及 `searchHint` 进行加权匹配，并支持 `+term` 强制包含语法。
- **缓存策略**：利用 `lodash-es/memoize` 缓存工具描述，并通过比对延迟工具集合的签名来自动失效缓存，减少重复的 Prompt 生成开销。
- **延迟判定逻辑**：`prompt.ts` 定义了 `isDeferredTool` 规则，默认将 MCP 工具和标记 `shouldDefer` 的工具设为延迟加载，但为 `BriefTool`、`AgentTool` 等核心通信工具提供了白名单豁免。
- **集成接口**：通过 `mapToolResultToToolResultBlockParam` 返回 `tool_reference` 类型的块，驱动底层 API 动态注入完整的工具 Schema。
