- **统一工具契约**：所有子模块遵循标准化的 `Tool` 接口定义，通过 `src/tools/utils.ts` 等共享工具处理消息标签（`sourceToolUseID`）与上下文关联，确保工具调用在 UI 中的状态同步。
- **多智能体编排中枢**：通过 `src/tools/shared/spawnMultiAgent.ts` 提供核心的子代理（Teammate）孵化能力，支持基于 tmux/iTerm2 的分屏视图或进程内（In-Process）隔离模式，并自动处理团队文件（Team File）的持久化与邮箱通信初始化。
- **跨域基础设施共享**：`src/tools/shared/` 目录封装了 Git 操作追踪（`gitOperationTracking.ts`）等通用逻辑，供 Bash、PowerShell 等多个执行类工具复用，实现统一的指标上报与审计。
- **模块化 UI 集成**：每个工具子模块独立维护其 React 组件（`UI.tsx`），由引擎层根据工具类型动态加载并注入到主交互界面，实现逻辑与表现的解耦。
