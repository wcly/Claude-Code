- **TaskOutputTool**: 基于 `buildTool` 构建的只读工具，通过 `waitForTaskCompletion` 轮询应用状态，利用 `getTaskOutputData` 统一处理 LocalShell、LocalAgent 及 RemoteAgent 的不同输出结构，并通过 React 组件实现差异化的 UI 渲染。
- **McpAuthTool**: 采用工厂模式 `createMcpAuthTool` 动态生成伪工具，在 `call` 中触发 `performMCPOAuthFlow` 并返回授权 URL，认证成功后通过 `reconnectMcpServerImpl` 自动替换应用状态中的工具列表。
