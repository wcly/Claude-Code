- **核心入口**：`LSPTool.ts` 基于 `buildTool` 框架实现，负责生命周期管理、输入校验及与 `../../services/lsp/manager.js` 的通信。
- **请求编排**：内部将高层操作（如 `incomingCalls`）拆解为多步 LSP 请求（先 `prepareCallHierarchy` 后获取具体调用），并统一处理文件打开与大小限制（10MB）。
- **结果格式化**：`formatters.ts` 负责将 LSP 原始类型转换为可读文本，包含按文件分组、相对路径转换及 Git 忽略文件过滤逻辑。
- **展示层**：`UI.tsx` 利用 React 组件渲染折叠/展开的结果摘要；`symbolContext.ts` 提供同步符号提取以增强交互上下文。
- **契约定义**：`schemas.ts` 使用 Zod 定义区分联合类型（Discriminated Union），确保 9 种操作的类型安全。
