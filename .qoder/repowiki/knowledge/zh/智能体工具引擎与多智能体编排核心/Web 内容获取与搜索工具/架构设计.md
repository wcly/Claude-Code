- **分层结构**：每个子工具（WebFetch, WebSearch）遵循 `Tool.ts` (核心逻辑/权限), `prompt.ts` (系统提示词), `UI.tsx` (渲染组件) 的分层设计。
- **依赖方向**：核心逻辑依赖于底层 API 服务 (`queryHaiku`, `queryModelWithStreaming`) 和通用工具类 (`buildTool`, `lazySchema`)。
- **接口边界**：通过 `buildTool` 工厂函数统一暴露工具定义，实现标准化的输入校验、权限检查和结果渲染。
- **内部实现**：`WebFetchTool` 包含独立的 `utils.ts` 处理 HTTP 请求、缓存 (LRUCache) 和 HTML 转 Markdown；`WebSearchTool` 直接集成 Anthropic SDK 的 `web_search_20250305` 能力。
