- **通用代理模式**：`MCPTool` 作为动态代理，其核心逻辑（名称、描述、调用）在 `mcpClient.ts` 中运行时注入，本地仅保留 Schema 定义与 UI 渲染逻辑。
- **专用资源工具**：`ListMcpResourcesTool` 和 `ReadMcpResourceTool` 为静态定义的只读工具，通过 `ensureConnectedClient` 与 MCP 服务器交互，支持 LRU 缓存与并发安全。
- **UI 与表现层**：各模块均包含 `UI.tsx`，负责将工具输入/输出渲染为 React 节点，支持进度条、JSON 格式化及二进制内容（Blob）的持久化提示。
- **辅助分类器**：`classifyForCollapse.ts` 维护了庞大的搜索/读取工具白名单，用于前端 UI 对 MCP 工具调用进行折叠优化。
