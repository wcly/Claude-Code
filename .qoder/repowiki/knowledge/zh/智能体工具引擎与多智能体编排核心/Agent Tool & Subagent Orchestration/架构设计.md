- **UI 渲染层** (`UI.tsx`): 基于 React/Ink 实现 Agent 执行状态的可视化，包括进度条聚合 (`processProgressMessages`)、详细转录视图 (`VerboseAgentTranscript`) 及结果展示。
- **定义加载层** (`loadAgentsDir.ts`): 负责解析内置、用户自定义 (Markdown/JSON) 及插件代理定义，支持 MCP 服务器依赖检查、内存快照初始化及工具权限过滤。
- **Fork 核心逻辑** (`forkSubagent.ts`): 实现隐式 Fork 实验特性，通过 `buildForkedMessages` 构造字节级一致的 API 前缀以优化提示词缓存，并利用 `buildChildMessage` 注入严格的子代理执行约束。
- **数据流**: 加载器生成 `AgentDefinition` 供工具调用，UI 组件消费 `ProgressMessage` 进行实时状态反馈。
