- 模块内可变状态集中在 `sessionMemoryUtils.ts` 管理，并提供成对的标记函数（如 `markExtractionStarted`/`markExtractionCompleted`）以维护提取生命周期。
- 所有后台提取均通过 `runForkedAgent` 执行，并传入由 `createSubagentContext` 生成的隔离上下文，避免副作用泄漏到主循环。
- 文件系统操作统一使用 `getFsImplementation()` 抽象层，并在初始化目录/文件时设置严格权限（目录 0o700、文件 0o600）。
- 提示构建采用模板加载 + 变量替换模式（`{{currentNotes}}`、`{{notesPath}}`），支持用户自定义模板与提示文件回退到默认值。
- 阈值判断与状态更新解耦：`shouldExtractMemory` 只读判断，状态变更由工具函数（如 `markSessionMemoryInitialized`、`recordExtractionTokenCount`）完成。
