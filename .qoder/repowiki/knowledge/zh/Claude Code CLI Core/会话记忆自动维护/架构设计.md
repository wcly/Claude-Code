- 入口与注册：`sessionMemory.ts` 导出 `initSessionMemory`，在自动压缩启用且非远程模式时通过 `registerPostSamplingHook` 注册后置采样钩子 `extractSessionMemory`。
- 触发策略：基于令牌阈值（初始化/增量）与工具调用次数双重条件，并在最后一轮无工具调用时优先触发，由 `shouldExtractMemory` 与 `sessionMemoryUtils.ts` 中的状态机共同决定。
- 执行隔离：使用 `runForkedAgent` 创建隔离的 `ToolUseContext`（克隆文件读取缓存、独立中止控制器等），确保不污染主代理状态；权限上通过 `createMemoryFileCanUseTool` 仅允许对记忆文件执行 `FILE_EDIT_TOOL_NAME`。
- 持久化与模板：`setupSessionMemoryFile` 负责目录与文件初始化（严格权限），缺失时写入默认模板；`prompts.ts` 提供默认模板与可自定义的 `template.md`/`prompt.md`，并通过变量替换构建更新提示。
- 手动触发：`manuallyExtractSessionMemory` 绕过阈值检查，供 `/summary` 等命令使用；共享相同的隔离执行与权限约束。
- 配置来源：通过 GrowthBook 动态配置缓存值初始化 `SessionMemoryConfig`，保证非阻塞加载与合理默认值。
