- **分层架构**：模块划分为配置层（`schemas.ts` 定义 Zod 校验规则）、管理层（`marketplaceManager.ts` 处理市场同步与 Git 操作）、存储层（`installedPluginsManager.ts` 维护 `installed_plugins.json` 状态）及加载层（`pluginLoader.ts` 执行物理安装与缓存）。
- **数据流设计**：采用“意图-状态”分离模型，用户配置存储在 `settings.json`，而实际安装元数据持久化在 `known_marketplaces.json` 和 `installed_plugins.json` 中。
- **缓存策略**：实现基于 `{marketplace}/{plugin}/{version}` 的版本化目录结构，并支持 ZIP 压缩缓存以优化 I/O；引入 Seed 目录机制支持只读预置插件。
- **安全边界**：通过 `schemas.ts` 中的 `ALLOWED_OFFICIAL_MARKETPLACE_NAMES` 和 `BLOCKED_OFFICIAL_NAME_PATTERN` 实施官方市场名称保护，防止第三方恶意仿冒。
