- **Global State Hub**: `src/bootstrap/state.ts` acts as the central singleton for session identity, cost tracking, and feature flags, serving as the primary dependency for cross-cutting concerns.
- **Permission & Safety Gate**: `src/utils/permissions/` implements a multi-layered decision engine (rules, hooks, and AI classifiers) that intercepts tool execution requests before they reach the runtime.
- **Telemetry & Observability Fabric**: A unified pipeline where `sideQuery.ts` handles out-of-band API calls, `sessionTracing.ts` manages OpenTelemetry spans, and `analytics/index.ts` provides a decoupled event sink for product metrics.
- **Extensibility Boundary**: `src/utils/hooks.ts` and `src/services/mcp/` define the contracts for external plugins and model-context-protocol servers, isolating third-party logic from the core agent loop.
- **Test Infrastructure**: `src/services/vcr.ts` provides a deterministic replay layer for API interactions, enabling robust integration testing without live network dependencies.
