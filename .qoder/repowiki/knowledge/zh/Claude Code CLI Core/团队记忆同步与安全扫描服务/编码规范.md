- 所有可变同步状态（如 lastKnownChecksum, serverChecksums）均封装在 `SyncState` 对象中并通过参数传递，严禁使用模块级可变全局变量，以确保测试隔离性。
- 在执行文件写入或上传前，必须对相对路径键（relative key）进行严格的边界校验，包括空字节检查、URL 编码解码以及通过 realpath 解析符号链接后的包含关系验证。
- 敏感信息扫描采用“失败即跳过”原则，检测到密钥的文件不会进入上传队列，且日志中仅记录规则 ID 和标签，严禁记录或传输密钥的具体值。
- API 错误处理统一使用 `classifyAxiosError` 进行分类，并根据错误类型（auth, timeout, network, conflict）决定是否需要重试或直接终止流程。
