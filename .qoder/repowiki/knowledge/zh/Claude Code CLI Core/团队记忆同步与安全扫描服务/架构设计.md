- **核心同步逻辑**：`index.ts` 实现了基于 ETag 和 SHA-256 内容哈希的增量同步机制。通过 `SyncState` 管理服务端校验和（serverChecksums），支持 Pull（服务端优先）和 Push（本地优先/乐观锁）操作。
- **冲突解决策略**：Push 遇到 412 冲突时，调用 `fetchTeamMemoryHashes` 仅获取元数据哈希以刷新本地状态，重新计算差异后重试，避免下载完整内容。
- **安全边界**：集成 `secretScanner.ts` 在读取本地文件时进行预扫描，匹配 gitleaks 规则的文件会被跳过并记录；`teamMemSecretGuard.ts` 提供写前拦截，防止模型将密钥写入团队目录。
- **路径验证**：依赖 `src/memdir/teamMemPaths.ts` 中的 `validateTeamMemKey` 和 `realpathDeepestExisting`，通过解析符号链接和规范化路径来防御目录遍历攻击。
- **文件监听**：`watcher.ts` 使用原生 `fs.watch`（递归模式）监控目录变化，通过防抖（2000ms）触发推送，并处理永久失败状态的抑制逻辑。
