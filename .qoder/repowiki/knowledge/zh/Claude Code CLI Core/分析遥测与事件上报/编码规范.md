- 所有对外暴露的事件记录入口位于 `index.ts`，内部后端（Datadog/1P）不直接被业务代码调用，确保依赖方向由外向内。
- 通过 `_PROTO_*` 前缀标记需进入特权列的元数据键，并在进入通用存储（如 Datadog）前统一剥离，仅在 1P 导出器中提升为 proto 字段。
- 采用启动期事件队列与 `queueMicrotask` 异步排空机制，避免在应用初始化关键路径上引入同步阻塞。
- 对可能包含敏感信息的字符串元数据使用标记类型 `AnalyticsMetadata_I_VERIFIED_THIS_IS_NOT_CODE_OR_FILEPATHS` 进行编译期约束，限制直接传入自由文本。
- 各后端均实现独立的禁用/熔断检查（环境变量、隐私级别、GrowthBook 门控与 per-sink killswitch），并在派发点快速短路以减少无效 IO。
