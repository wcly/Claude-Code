- 入口层：`index.ts` 定义 `AnalyticsSink` 接口并提供 `logEvent`/`logEventAsync`，在 sink 未就绪前通过内存队列缓冲事件，随后由 `attachAnalyticsSink` 异步排空。
- 路由层：`sink.ts` 实现具体分发逻辑，集成采样（`firstPartyEventLogger.shouldSampleEvent`）、功能门控（`growthbook`）与熔断（`sinkKillswitch`），并将 PII 标记字段从通用后端剥离后分别投递至 Datadog 与 1P 日志。
- 后端实现：`datadog.ts` 基于 HTTP 批量聚合与定时刷写将白名单事件上报至 Datadog；`firstPartyEventLogger.ts` 基于 OpenTelemetry Logs SDK 构建独立 `LoggerProvider`，经 `FirstPartyEventLoggingExporter` 将结构化载荷发送至 `/api/event_logging/batch`，支持磁盘持久化失败重试、动态批次配置热更新以及 GrowthBook 实验曝光上报。
- 支撑模块：`metadata.ts` 统一 enrich 环境与进程上下文；`config.ts` 集中判定遥测禁用条件；`growthbook.ts` 管理远程特性评估缓存与刷新信号；`sinkKillswitch.ts` 提供按后端的动态开关。
