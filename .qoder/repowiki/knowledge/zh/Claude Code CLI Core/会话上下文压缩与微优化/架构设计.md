- 核心入口：`compact.ts` 提供全量与部分压缩逻辑，通过 forked agent 调用 API 生成摘要。
- 自动化调度：`autoCompact.ts` 监控 Token 阈值并触发压缩，支持会话记忆优先策略 (`sessionMemoryCompact.ts`)。
- 微优化层：`microCompact.ts` 实现基于时间间隔的工具结果内容清除及缓存编辑（Cache Editing）路径。
- 辅助模块：`prompt.ts` 定义结构化摘要模板；`grouping.ts` 按 API 轮次分组消息；`postCompactCleanup.ts` 负责压缩后的状态重置与缓存清理。
