- **核心编排**：`OAuthService` (`index.ts`) 作为状态机管理整个认证生命周期，协调 `AuthCodeListener`（本地 HTTP 服务器）与 `client.ts`（API 交互）。
- **双模认证流**：通过 `startOAuthFlow` 支持自动模式（打开浏览器监听 localhost 回调）和手动模式（用户粘贴代码），由 `waitForAuthorizationCode` 统一收敛结果。
- **安全原语**：`crypto.ts` 封装了符合 RFC 7636 标准的 PKCE 逻辑（S256 挑战码生成）及 CSRF 防护所需的 State 生成。
- **网络交互层**：`client.ts` 负责与 Anthropic/Claude AI 服务端点通信，执行 Code 换 Token、Token 刷新、Profile 拉取及 API Key 自动生成。
- **回调捕获**：`AuthCodeListener` (`auth-code-listener.ts`) 使用 Node.js `http` 模块创建临时本地服务器，解析重定向 URL 中的授权码并完成最终的用户端重定向。
