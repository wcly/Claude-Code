- **分层架构**：模块采用四层设计，`manager.ts` 提供全局单例入口与初始化状态机；`LSPServerManager.ts` 负责多服务器路由与文件扩展名映射；`LSPServerInstance.ts` 封装单个服务器的启停与健康检查；`LSPClient.ts` 基于 `vscode-jsonrpc` 实现底层 stdio 通信。
- **依赖方向**：配置层 `config.ts` 从插件系统动态加载服务器定义；`passiveFeedback.ts` 注册通知处理器，将 LSP 诊断转换为内部格式并写入 `LSPDiagnosticRegistry.ts`。
- **关键接口**：`LSPServerManager` 定义了 `sendRequest`、`openFile` 等核心交互接口；`LSPClient` 抽象了 JSON-RPC 连接细节。
- **证据文件**：`src/services/lsp/manager.ts`（单例控制），`src/services/lsp/LSPServerManager.ts`（路由逻辑），`src/services/lsp/LSPClient.ts`（通信底层）。
