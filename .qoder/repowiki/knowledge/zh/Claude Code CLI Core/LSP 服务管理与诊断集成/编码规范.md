- 采用工厂函数模式（Factory Function）配合闭包封装私有状态，避免使用 ES6 Class 定义核心组件（如 `createLSPServerManager`、`createLSPServerInstance`）。
- 在模块级单例初始化中引入“代次计数器”（generation counter）机制，防止并发或重试场景下的旧异步任务覆盖最新状态。
- 对重型依赖（如 `vscode-jsonrpc`）实施懒加载（Lazy Require），仅在实例化具体 LSP 客户端时动态引入，以降低静态导入开销。
- 所有异步资源清理（如 `shutdown`、`stop`）均采用“尽力而为”策略，确保即使部分步骤失败也能清除内存引用并防止子进程泄漏。
