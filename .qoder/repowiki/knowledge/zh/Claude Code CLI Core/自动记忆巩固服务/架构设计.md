- **入口与生命周期**：`initAutoDream()` 初始化闭包状态并返回 `runner`，由 `executeAutoDream()` 作为钩子入口调用。
- **门控机制**：依次执行时间门控（基于锁文件 mtime）、会话扫描节流、会话数量门控及并发锁获取。
- **核心执行**：通过 `runForkedAgent` 启动只读权限的分叉代理，利用 `buildConsolidationPrompt` 生成的提示词进行记忆整理。
- **状态管理**：依赖 `consolidationLock.ts` 维护 `.consolidate-lock` 文件的 mtime 作为最后巩固时间戳，并通过 PID 检查实现进程间互斥。
- **配置驱动**：`config.ts` 结合本地设置与 GrowthBook 特性开关决定功能启用状态。
