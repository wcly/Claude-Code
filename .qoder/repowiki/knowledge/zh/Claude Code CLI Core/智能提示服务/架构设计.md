- 采用分层架构：`types.ts` 定义基础类型接口，`tipRegistry.ts` 维护提示规则库和相关性判断逻辑，`tipHistory.ts` 处理提示展示历史记录，`tipScheduler.ts` 负责提示选择策略和展示记录。
- 提示注册表 (`tipRegistry.ts`) 包含外部提示和内部提示两个数组，每个提示对象包含 id、内容生成函数、冷却期和相关性判断函数。
- 历史记录模块 (`tipHistory.ts`) 基于全局配置中的启动次数来追踪每个提示的最后展示时间，计算距离上次展示的会话间隔。
- 调度器模块 (`tipScheduler.ts`) 提供核心 API：`getTipToShowOnSpinner` 获取待展示提示，`selectTipWithLongestTimeSinceShown` 实现最长未展示优先的选择策略，`recordShownTip` 记录展示并上报分析事件。
- 依赖方向：调度器依赖注册表和历史记录，注册表依赖历史记录进行冷却期判断，所有模块依赖全局配置和设置工具。
