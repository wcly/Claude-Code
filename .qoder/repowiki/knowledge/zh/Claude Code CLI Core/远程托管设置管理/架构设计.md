- **入口与编排**：`index.ts` 作为核心控制器，协调 `fetchWithRetry`（带指数退避的重试逻辑）、`syncCacheState.ts`（持久化与内存缓存）以及 `securityCheck.tsx`（安全校验）。
- **循环依赖解耦**：采用 `syncCacheState.ts` 作为无认证的叶子状态模块，将资格校验逻辑隔离在 `syncCache.ts` 中，从而打破 `settings.ts` → `auth.ts` → `settings.ts` 的启动期循环依赖。
- **安全拦截层**：通过 `securityCheck.tsx` 集成 Ink 渲染引擎，在检测到危险配置变更时弹出阻塞式对话框，用户拒绝则触发优雅退出。
- **兼容性适配**：同时存在 `securityCheck.jsx`（空实现）与 `securityCheck.tsx`（完整实现），`index.ts` 显式引用 `.jsx` 后缀以适配不同的构建或运行环境需求。
