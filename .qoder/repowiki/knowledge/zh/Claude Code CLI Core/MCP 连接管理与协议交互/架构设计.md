- **核心管理层**：`MCPConnectionManager.tsx` 提供 React Context，封装 `useManageMCPConnections` Hook，负责维护全局 MCP 客户端状态（连接、工具、命令、资源）并处理自动重连逻辑。
- **连接与传输层**：`client.ts` 是核心实现，根据配置动态实例化 `Stdio`、`SSE`、`StreamableHTTP`、`WebSocket` 或 `InProcess` 传输层，并管理 `@modelcontextprotocol/sdk` 的 Client 生命周期。
- **认证与安全**：`auth.ts` 实现了复杂的 OAuth 2.1/OIDC 流程，包括 RFC 9728/8414 元数据发现、PKCE 授权码流、以及基于 XAA (Cross-App Access) 的跨应用令牌交换 (`xaa.ts`, `xaaIdpLogin.ts`)。
- **配置与策略**：`config.ts` 处理多作用域（项目、用户、企业）的配置合并、环境变量展开及基于 Allowlist/Denylist 的安全策略过滤。
- **高级交互**：`elicitationHandler.ts` 处理服务器发起的用户确认请求（Elicitation），`channelPermissions.ts` 支持通过外部渠道（如 Telegram）进行权限中继。
