- 所有 MCP 服务器配置类型（Stdio, SSE, HTTP 等）均通过 Zod Schema (`types.ts`) 进行严格定义和运行时校验，确保配置结构的类型安全。
- 敏感认证信息（如 OAuth Tokens, Client Secrets）统一通过 `secureStorage` (如 macOS Keychain) 进行持久化，严禁明文存储在普通配置文件中。
- 网络请求（Fetch）普遍采用包装器模式（`wrapFetchWithTimeout`, `createAuthFetch`），为每个请求注入独立的 AbortSignal 超时控制，避免长连接或 stale signal 导致的请求挂起。
- MCP 客户端的状态更新（连接状态、工具列表变更）采用批量处理机制（`pendingUpdatesRef` + `setTimeout`），将短时间内的多次状态变更合并为一次 React State 更新，以减少渲染开销。
