- **核心执行层** (`toolExecution.ts`)：实现 `runToolUse` 主流程，串联 Zod 输入校验、Pre/Post 钩子执行、权限决策 (`resolveHookPermissionDecision`) 及工具调用，并处理遥测与错误分类。
- **并发编排层** (`StreamingToolExecutor.ts`, `toolOrchestration.ts`)：提供流式与非流式两种执行模式。`StreamingToolExecutor` 基于状态机管理工具队列，支持并发安全工具并行执行及错误级联取消；`toolOrchestration` 则通过 `partitionToolCalls` 将工具调用划分为并发批或串行批。
- **钩子系统** (`toolHooks.ts`)：封装 `runPreToolUseHooks` 与 `runPostToolUseHooks`，处理钩子的异步迭代结果，包括权限拦截、输入修改及执行阻断逻辑。
