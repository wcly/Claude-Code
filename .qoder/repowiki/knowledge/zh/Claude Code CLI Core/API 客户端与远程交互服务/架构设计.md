- **核心通信层**：`client.ts` 基于 `@anthropic-ai/sdk` 动态适配多后端（First-party, Bedrock, Vertex, Foundry），处理认证头注入与代理配置。
- **业务交互模块**：按功能拆分为独立文件，如 `sessionIngress.ts` 处理会话日志的乐观并发追加，`grove.ts` 管理隐私设置，`referral.ts` 处理推荐资格。
- **可靠性中间件**：`withRetry.ts` 实现指数退避、模型降级及 529/429 错误处理；`promptCacheBreakDetection.ts` 监控提示词缓存命中率。
- **状态管理**：采用内存 Map（如 `lastUuidMap`）与磁盘配置（`GlobalConfig`）相结合的双层缓存策略，确保跨进程状态同步与离线可用性。
