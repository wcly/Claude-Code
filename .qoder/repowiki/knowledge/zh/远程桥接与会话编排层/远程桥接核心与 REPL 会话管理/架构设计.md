- **双路径架构**：模块支持 `initEnvLessBridgeCore`（直接通过 `/bridge` 接口获取 JWT 并建立 CCR v2 连接）和 `initBridgeCore`（基于 Environments API 的注册/轮询模型）。
- **传输抽象层**：定义 `ReplBridgeTransport` 接口，统一封装 v1 的 `HybridTransport`（WebSocket + HTTP POST）和 v2 的 `SSETransport` + `CCRClient`（SSE 读取 + HTTP 写入）。
- **核心组件**：`remoteBridgeCore.ts` 处理无环境路径的初始化、JWT 刷新调度及 401 恢复；`replBridge.ts` 实现基于环境的轮询循环、工作项分发及会话持久化指针（`bridgePointer`）。
- **消息处理**：`bridgeMessaging.ts` 提供通用的入站消息解析、控制请求响应及基于 `BoundedUUIDSet` 的回声去重逻辑。
- **配置管理**：通过 `envLessBridgeConfig.ts` 从 GrowthBook 动态获取重试策略、心跳间隔及超时阈值。
