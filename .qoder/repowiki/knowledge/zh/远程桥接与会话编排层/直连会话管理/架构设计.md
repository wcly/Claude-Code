- **入口函数**：`createDirectConnectSession.ts` 提供 `createDirectConnectSession` 异步函数，通过 HTTP POST 请求初始化会话并获取 WebSocket URL。
- **核心管理器**：`directConnectManager.ts` 导出 `DirectConnectSessionManager` 类，封装 WebSocket 连接生命周期（connect/disconnect）及消息解析逻辑。
- **类型定义**：`types.ts` 定义了会话状态（`SessionState`）、配置（`ServerConfig`）及索引结构（`SessionIndex`），并使用 `zod` 进行响应数据校验。
- **依赖方向**：管理器依赖于 `src/utils/slowOperations` 进行 JSON 处理，并通过回调模式（Callbacks）将消息和权限请求分发给上层调用者（如 React Hooks）。
