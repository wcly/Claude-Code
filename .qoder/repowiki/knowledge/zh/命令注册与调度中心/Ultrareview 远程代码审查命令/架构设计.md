- **入口与编排**：`ultrareviewCommand.tsx` 导出 `call` 函数（符合 `LocalJSXCommandCall` 接口），作为命令执行的顶层协调者，负责调用计费门控逻辑并根据状态渲染 UI 或启动后台任务。
- **业务逻辑层**：`reviewRemote.ts` 封装核心逻辑，包括 `checkOverageGate`（并行获取配额与用量以决定计费策略）和 `launchRemoteReview`（处理 PR 模式与分支模式的远程会话建立、环境参数注入及 `RemoteAgentTask` 注册）。
- **交互组件**：`UltrareviewOverageDialog.tsx` 是一个 React 组件，在用户免费额度用尽且开启额外使用时弹出，用于确认计费行为并管理取消/启动状态。
- **特性开关**：`ultrareviewEnabled.ts` 提供 `isUltrareviewEnabled` 函数，基于 GrowthBook 配置动态控制命令的可见性。
- **依赖方向**：模块内部逻辑单向依赖于外部的远程代理任务系统（`RemoteAgentTask`）、遥测服务（`logEvent`）以及 Git 工具类，实现了审查逻辑与底层通信机制的解耦。
