- **入口层**：各子目录（`session`, `config`, `clear`）通过 `index.ts` 导出符合 `Command` 接口的元数据，定义命令名称、别名及加载策略。
- **实现层**：采用懒加载机制（`load: () => import(...)`），`session` 和 `config` 使用 `local-jsx` 类型渲染 React 组件，`clear` 使用 `local` 类型执行异步逻辑。
- **核心逻辑**：`clear` 模块细分为 `clear.ts`（主入口）、`conversation.ts`（处理消息清空、任务终止、会话ID重置及钩子执行）和 `caches.ts`（处理全局缓存、技能、Git状态等底层清理）。
- **依赖方向**：UI 组件依赖 `state/AppState` 和 `ink.js`；清除逻辑深度依赖 `bootstrap/state`、`utils/sessionStorage` 及各类工具类缓存接口。
