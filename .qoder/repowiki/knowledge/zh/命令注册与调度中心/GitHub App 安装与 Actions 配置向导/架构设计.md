- **入口与注册**：`index.ts` 定义 `local-jsx` 类型命令，通过 `load` 动态导入主逻辑 `install-github-app.tsx`。
- **状态机驱动 UI**：`install-github-app.tsx` 维护 `State`（定义于 `types.ts`），通过 `step` 字段在多个 React 组件步骤间切换（如 `CheckGitHubStep`、`ChooseRepoStep`、`InstallAppStep`、`ApiKeyStep`、`CreatingStep` 等）。
- **核心业务逻辑**：`setupGitHubActions.ts` 封装底层操作，包括通过 `gh api` 创建分支、上传工作流文件（`claude.yml` 等）、设置仓库密钥（`gh secret set`）以及打开浏览器发起 PR。
- **外部依赖交互**：重度依赖 `execa` 和自定义 `execFileNoThrow` 工具执行 `gh` (GitHub CLI) 命令，并通过 `openBrowser` 处理 OAuth 或 App 安装跳转。
