- **全局状态单例**：`src/bootstrap/state.ts` 导出基于模块级 `STATE` 对象的读写 API，集中管理会话 ID、成本、模型使用率及遥测计数器（OpenTelemetry）。
- **上游代理中继**：`src/upstreamproxy/` 实现本地 TCP 到远程 WebSocket 的 CONNECT 隧道（`relay.ts`），支持 Node.js 和 Bun 运行时，用于在 CCR 容器中安全转发流量。
- **代理初始化与配置**：`upstreamproxy.ts` 负责读取会话令牌、设置进程不可转储（prctl）、下载 CA 证书并注入环境变量（HTTPS_PROXY）。
- **功能存根与加载器**：`src/moreright/` 提供外部构建用的 React Hook 存根；`src/outputStyles/` 提供基于 Markdown 的输出样式配置加载器。
