- **Buddy 子系统**：采用确定性随机算法（`companion.ts`）基于用户 ID 生成宠物属性，通过 `CompanionSprite.tsx` 在终端进行 ASCII 动画渲染，并利用 React Hooks 管理状态与通知。
- **Coordinator 子系统**：通过环境变量与特性开关控制协调者模式，定义 Worker 代理的系统提示词（`coordinatorMode.ts`）及工具权限上下文，实现多智能体任务的编排。
- **Assistant 子系统**：提供会话历史的分页检索接口（`sessionHistory.ts`），支持基于 OAuth 的身份验证与游标分页查询。
